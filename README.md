# Форма — особистий щоденник тренувань

Прототип українською мовою для запису тренувань у спортзалі. Увесь застосунок міститься в `index.html`: HTML, CSS та JavaScript, без зовнішніх залежностей.

## Як запустити

Завантажте репозиторій через **Code → Download ZIP**, розпакуйте архів і відкрийте `index.html` у сучасному браузері. Встановлення та збирання не потрібні.

## Можливості

- Каталог вправ і додавання власних вправ.
- Запис ваги, повторень і виконаних підходів.
- Таймер відпочинку.
- Створення програм із поточного тренування та їх повторне використання.
- Історія тренувань, максимальні ваги та обсяг виконаних підходів.
- Експорт та імпорт резервної копії у JSON.

## Збереження даних

Дані зберігаються в localStorage цього браузера. Записи тренувань не передаються до GitHub. Очищення даних браузера видалить локальні записи, тому періодично завантажуйте резервну копію у вкладці «Дані». На іншому пристрої копію можна імпортувати вручну.

Це початковий вебпрототип. Хмарна синхронізація, облікові записи та окремий застосунок для iPhone ще не реалізовані. Публікація коду в цьому репозиторії сама по собі не публікує сайт і не створює застосунок в App Store.
